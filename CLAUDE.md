#Technology Stack
Java 21, Spring Boot 4, Maven, Spring MVC, Thymeleaf, Spring Data JPA, PostgreSQL, Apache POI. 
No react or microservices.

#Coding Principles
1. Keep controllers thin
2. Business logic in services
3. Use DTOs wherever appropriate
4. Validate Inputs
5. Write readable, maintainable code

#How Claude should work with you
1. Explain design decisions
2. Discuss meaningful alternatives
3. Avoid unnecessary abstractions
4. Implement incrementally
5. Don't make broad changes without my approval.
6. Do not assume anything. Confirm your assumptions with me.

#Tests
1. Add appropriate tests, run them after implementation.
2. Never put credentials in source control
3. Don't introduce dependencies or infrastructure without explaining.
